## 🔑 Key Technical Knowledge (Don't Rediscover)

1. **Transaction model is `WalletTransaction`** (not `Transaction`) in `lib/features/transaction/models/transaction.dart`. Useful getters: `displayTitle`, `signedAmount`, `isIncoming`, `isOutgoing`.

2. **Formatter is `formatZmw()`** (not `formatCurrency`) in `lib/core/utils/formatters.dart`. Signature: `formatZmw(dynamic raw, {bool includeSymbol = true})`.

3. **`TransactionTile` takes primitives, not a model:** `{title, subtitle, amountText, incoming, icon?, onTap?}` — defined in `lib/core/widgets/widgets.dart`.

4. **Flutter version uses RadioGroup** (post-3.32): individual `Radio`/`RadioListTile` no longer take `groupValue`/`onChanged`. Wrap children in `RadioGroup<T>(groupValue:, onChanged:, child:)`.

5. **Design tokens:** Unused primitives are commented out with "Reserved for future use" markers — the dark-mode palette lives there ready for Phase 2. Do NOT delete these comments.

6. **Transitions:** `AppPageRoute` in `page_transitions.dart` — the transitionsBuilder callback signature is the raw function type, not `PageTransitionsBuilder`.

7. **Router:** GoRouter + ShellRoute; auth gate via `refreshListenable: authProvider`; redirect logic in `GoRouterForApp._redirect`. Bottom nav tabs: `/wallet`, `/send`, `/cards`, `/profile`.
