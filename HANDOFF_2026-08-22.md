## 8) Research digest (this session's findings — cite-worthy)

**Lipila (PRIMARY gateway rec)** — Zambia-native; MTN/Airtel/**Zamtel Kwacha** collections + disbursements; card collections; bank disbursements. Self-onboard sandbox: https://dashboard.lipila.dev · Live: https://dashboard.lipila.io/onboarding/sign-up. API keys: Dashboard → Wallets → view more details → API Keys section; secret keys start **`Lsk`**; Test vs Live keys (wrong env → 401). Disbursements require server IP whitelisting. Callback JSON fields: referenceId/status(Pending|Successful|Failed)/amount/accountNumber/paymentType(MtnMoney|AirtelMoney|ZamtelKwacha)/identifier/message. MTN USSD fallback *115# when prompts delay. Official Flutter SDK: `lipila_flutter` (pub.dev).

**Lenco (SECONDARY — bank rails/virtual accounts)** — Lenco by BroadPay; API v2 `https://api.lenco.co/access/v2` bearer auth; MoMo collections/transfers operators `airtel|mtn|zamtel` (ZM + MW); status verify GET `/collections/status/:reference`; webhooks e.g. `collection.successful`. Business account KYC docs: certificate of incorporation, Form III / PACRA printout (<3 months), directors' IDs, website URL/APK, corporate bank account details.

**Competitive landscape:** ChitChat (onchitchat.com) = pivot of Zazu after Union54's $1.2B chargeback fraud attempt halted Union54; Mastercard virtual debit cards launched Sep 2024; chat-first USD wallets, sends to 13+ countries. Public complaints: lost MoMo deposits vs Zazu era, USD-only wallets, $5/mo card fees, slow KYC. Zazu cards were issued by Union54 (BoZ licence 04/PSB/2018). Paystack does NOT cover Zambia (original plan's 11.2 assumption wrong).

**Gateway verdict recorded in PROJECT-PLAN:** Lipila primary (Flutter SDK + all 3 operators + sandbox self-onboarding) → Lenco complement (bank/virtual accounts) → Flutterwave fallback for cross-border later.
